# deepseek-balance 接口文档

本插件对外只有两类接口：**CLI 脚本接口**（`scripts/balance.mjs`）与**账本文件接口**。此外记录两个上游 DeepSeek 接口的用法，便于排障。

## 1. CLI 接口

入口：`scripts/balance.mjs`，用 `node` 执行，要求 Node >= 18。

```
node balance.mjs balance [--json] [--mode ledger|token] [--state-dir <目录>]
node balance.mjs today   [--json] [--mode ledger|token] [--state-dir <目录>]
node balance.mjs --help
```

### 子命令

| 子命令 | 说明 | 是否写账本 |
| --- | --- | --- |
| `balance`（默认） | 拉余额 + 计算今日已用 | 是（记录本次余额观测） |
| `today` | 只计算今日已用 | 否 |

### 参数

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `--json` | 开关 | 关 | 输出机器可读 JSON |
| `--mode` | `ledger` \| `token` | `ledger`（或 `DEEPSEEK_BALANCE_MODE`） | 今日已用的计算模式 |
| `--state-dir` | 路径 | `%USERPROFILE%\.codex\deepseek-balance` | 账本目录，等价于 `DEEPSEEK_BALANCE_STATE_DIR` |
| `-h`, `--help` | 开关 | — | 打印用法 |

### 退出码

| 退出码 | 含义 |
| --- | --- |
| `0` | 成功（`ok: true`）；`token` 模式回落 `ledger` 也算成功 |
| `1` | 查询失败（`ok: false`），原因见 `code` |
| `2` | 用法错误（未知子命令） |

## 2. 输出结构

### 2.1 成功（`balance`）

```json
{
  "ok": true,
  "code": "ok",
  "updatedAt": "2026-09-11T16:22:43.474Z",
  "updatedAtLocal": "2026-09-12 00:22:43 +08:00",
  "isPeak": false,
  "stateFile": "C:\\Users\\<user>\\.codex\\deepseek-balance\\usage.json",
  "warnings": [],
  "credentialSource": "codex-config:model_providers.deepseek",
  "balance": {
    "totalBalance": 50.57,
    "currency": "CNY",
    "isAvailable": true,
    "grantedBalance": 0,
    "toppedUpBalance": 50.57,
    "pickedBy": "cny-positive"
  },
  "balanceInfos": [
    { "currency": "CNY", "totalBalance": 50.57, "grantedBalance": 0, "toppedUpBalance": 50.57 }
  ],
  "todayUsage": {
    "mode": "ledger",
    "amount": 0,
    "tokens": null,
    "date": "2026-09-12",
    "fallback": false,
    "ledgerWritable": true
  }
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `updatedAt` / `updatedAtLocal` | string | 本次查询时间（UTC ISO / 本地可读） |
| `isPeak` | boolean | 当前是否处于高峰计价时段 |
| `stateFile` | string | 本次使用的账本文件绝对路径 |
| `warnings` | string[] | 非致命告警（账本不可写、令牌模式回落等） |
| `credentialSource` | string | 密钥来源：`env:DEEPSEEK_API_KEY` 或 `codex-config:model_providers.<name>` |
| `balance.pickedBy` | string | 选币命中分支：`cny-positive` / `any-positive` / `cny` / `first` |
| `todayUsage.mode` | string | 实际生效模式：`ledger` 或 `token` |
| `todayUsage.amount` | number | 今日已用金额（CNY） |
| `todayUsage.tokens` | number \| null | 令牌模式下的 token 总数；记账模式为 `null` |
| `todayUsage.fallback` | boolean | 是否由 `token` 回落到 `ledger` |
| `todayUsage.ledgerWritable` | boolean \| null | 账本是否写入成功；`today` 子命令为 `null` |

`today` 子命令额外带 `todayUsage.observation`：最近一次余额观测的 UTC 时间戳（`null` 表示尚无观测）。

### 2.2 失败

```json
{ "ok": false, "code": "no_api_key", "error": "未找到 DeepSeek API key：……" }
```

| `code` | 触发条件 | 处理建议 |
| --- | --- | --- |
| `no_api_key` | 环境变量与 `~/.codex/config.toml` 都拿不到密钥 | 设置 `DEEPSEEK_API_KEY` 或补全 Codex 的 DeepSeek provider |
| `http_4xx` | 余额接口返回 4xx（密钥无效/无权限） | 检查密钥；不重试 |
| `http_5xx` | 余额接口返回 5xx（含重试后仍失败） | 稍后再试 |
| `network` | 网络错误或超时（重试 1 次后仍失败） | 检查网络/代理；沙箱需放行网络 |
| `parse` | 余额接口响应不是合法 JSON | 通常是网关或代理返回了错误页 |
| `shape` | 响应缺少 `balance_infos[].total_balance` | 上游结构变更，需更新脚本 |
| `internal` | 脚本内部异常 | 看 `error` 里的堆栈 |

## 3. 账本文件

默认路径 `%USERPROFILE%\.codex\deepseek-balance\usage.json`（可用 `--state-dir` / `DEEPSEEK_BALANCE_STATE_DIR` 覆盖）。

```json
{
  "version": 1,
  "date": "2026-09-12",
  "lastBalance": 50.57,
  "lastCurrency": "CNY",
  "todayUsage": 0.5,
  "lastSeenAt": "2026-09-11T16:22:43.660Z",
  "history": { "2026-09-11": 1.23 }
}
```

| 字段 | 说明 |
| --- | --- |
| `version` | 账本格式版本，当前 `1` |
| `date` | 账本归属日期（本地时区 `YYYY-MM-DD`） |
| `lastBalance` / `lastCurrency` | 上一次观测的余额与币种（差值基准） |
| `todayUsage` | 当日累计用量金额 |
| `lastSeenAt` | 最近一次观测时间（UTC ISO，`null` 表示尚无观测） |
| `history` | 历史归档：日期 → 当日用量，只保留最近 30 天 |

记账规则：

1. `date` 与当天不同 → 先把旧 `todayUsage` 归档进 `history`，`date` 归当天，`todayUsage` 归 0，`lastBalance` 取当前余额（**不计差值**）。
2. 币种与 `lastCurrency` 不同 → 只重置 `lastBalance` / `lastCurrency`，不记差值（防止多币种账户切换污染账本）。
3. 其余情况 → 当前余额低于 `lastBalance` 时把差值累加进 `todayUsage`；余额上升（充值）只更新基准、不扣减。
4. 归档超过 30 天的 `history` 条目被删除。

## 4. 环境变量

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `DEEPSEEK_API_KEY` | 无 | 余额接口密钥，优先级高于 Codex 配置 |
| `DEEPSEEK_PLATFORM_TOKEN` | 无 | 平台会话令牌，`token` 模式使用；可带 `Bearer ` 前缀 |
| `DEEPSEEK_BALANCE_MODE` | `ledger` | 默认用量模式 |
| `DEEPSEEK_BALANCE_STATE_DIR` | `%USERPROFILE%\.codex\deepseek-balance` | 账本目录 |
| `CODEX_HOME` | `%USERPROFILE%\.codex` | 读取 `config.toml` 的位置 |

## 5. 上游接口

### 5.1 余额

```
GET https://api.deepseek.com/user/balance
Authorization: Bearer <DEEPSEEK_API_KEY>
```

超时 20 秒；网络错误/超时/5xx 重试 1 次（间隔 500ms），4xx 不重试。

响应：

```json
{
  "is_available": true,
  "balance_infos": [
    { "currency": "CNY", "total_balance": "50.57", "granted_balance": "0.00", "topped_up_balance": "50.57" }
  ]
}
```

`balance_infos` 顺序不固定，多币种时按上文选币规则挑展示项。

### 5.2 平台用量（仅 `token` 模式）

```
GET https://platform.deepseek.com/api/v0/usage/by_api_key/amount?start=<本地零点秒>&end=<start+86400>&tz=<时区秒偏移>
Authorization: Bearer <DEEPSEEK_PLATFORM_TOKEN>
```

超时 15 秒。响应分桶路径：`data.biz_data.series[]`，每项 `{ model, buckets: [{ time, usage: { RESPONSE_TOKEN, PROMPT_CACHE_HIT_TOKEN, PROMPT_CACHE_MISS_TOKEN } }] }`。接口只返回 token 数，不返回金额，金额由本地定价表换算。

## 6. 定价表与峰谷规则

单位：人民币元 / 百万 token，数组为 `[空闲时段, 高峰时段]`。

| 模型匹配 | 缓存命中输入 | 缓存未命中输入 | 输出 |
| --- | --- | --- | --- |
| `deepseek-v4-flash` / `deepseek-chat` / `deepseek-reasoner` / `deepseek-v4-flash-vision-exp`（默认） | 0.05 / 0.10 | 1.5 / 3.0 | 4.5 / 9.0 |
| `deepseek-v4-pro` | 0.15 / 0.30 | 4.5 / 9.0 | 13.5 / 27.0 |

- 高峰时段：工作日（北京时间）9:00–12:00 与 14:00–18:00
- 2026-08-23（北京时间）起，周末（周六/周日）全天按谷价；该时刻之前的历史分桶仍按旧规则
- 判定按每个小时桶的整点，常量位于 `scripts/balance.mjs` 顶部：`PEAK_HOURS`、`BASE_PRICE`、`PRO_PRICE`、`PRICING`、`WEEKEND_VALLEY_FROM_SEC`
- 模型匹配方式为「模型名包含表内键」，未命中一律按默认单价

## 7. 悬浮挂件接口

主程序：`scripts/widget.ps1`（PowerShell 5.1 + WPF，独立进程，不走 Codex UI）。

```
powershell -NoProfile -ExecutionPolicy Bypass -File widget.ps1 -Action <动作> [-Interval 60]
```

| Action | 行为 | 退出码 |
| --- | --- | --- |
| `spawn` | 后台启动：用 WMI 创建 `wscript.exe widget-launch.vbs`，脱离调用方进程树与沙箱令牌，命令立即返回 | 0 成功 / 1 失败 |
| `start` | 前台启动，阻塞到窗口关闭；已在运行则只提示 | 0 |
| `stop` | 按 pid 文件结束进程并删除 pid 文件 | 0 |
| `status` | 打印运行状态、pid、开机自启状态、状态文件路径、缩放/模式/音效/气泡摘要 | 0 |
| `autostart-on` | 在「启动」目录写入 `DeepSeek 余额挂件.lnk`（指向 `wscript.exe widget-launch.vbs`） | 0 成功 / 1 启动器缺失 |
| `autostart-off` | 删除该快捷方式 | 0 |

`-Interval` 为自动刷新秒数，默认 60，最小按 10 生效。

### 7.1 状态文件 `widget.json`

路径 `%USERPROFILE%\.codex\deepseek-balance\widget.json`（与账本同目录，可用 `DEEPSEEK_BALANCE_STATE_DIR` 覆盖目录）。

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `scale` | number | 1.5 | 缩放倍数，范围 0.6–2.5，基准尺寸 320 DIP |
| `left` / `top` | number \| null | null | 未吸附轴的坐标（DIP）；null 表示首次运行时贴右下角 |
| `snapH` | `"left"` \| `"right"` \| null | `"right"` | 水平吸附；`"left"` 时整体水平镜像 |
| `snapV` | `"top"` \| `"bottom"` \| null | `"bottom"` | 垂直吸附 |
| `sound` | bool | true | 音效开关 |
| `soundSet` | `"duck"` \| `"fx1"` | `"duck"` | 音效集：小黄鸭 / 音效1 |
| `volume` | number | 0.6 | 音量 0–1，0 视为静音 |
| `usageMode` | `"ledger"` \| `"token"` | `"ledger"` | 透传给 `balance.mjs --mode` |
| `peakMode` | `"default"` \| `"liangwen"` \| `"qiangqiang"` | `"default"` | 峰谷文案：空闲/高峰时段、梁文谷/梁文峰、!?谷谷?!/!?峰峰?! |
| `bubbleOn` | bool | true | 气泡总开关 |

开机自启状态不写入本文件，以「启动」目录中是否存在 `DeepSeek 余额挂件.lnk` 为唯一判据。

### 7.2 运行期文件

| 文件 | 说明 |
| --- | --- |
| `widget.pid` | 当前挂件进程 pid；`stop` 与单实例判断都基于它 |
| `widget.log` | 运行日志（启动、停止、取数失败、未处理异常等），超过 100KB 时自动轮转 |
| `widget-snapshot.png` | 仅在 `DEEPSEEK_WIDGET_SNAPSHOT=1` 启动时生成，用于核对渲染（挂件是分层窗口，GDI 截屏抓不到） |

### 7.3 与取数的关系

挂件每 `Interval` 秒执行一次 `node <plugin>/scripts/balance.mjs balance --json --mode <usageMode>`，读取 `ok/balance.totalBalance/balance.currency/todayUsage.amount/isPeak`。
取数失败时保留上一次成功值，并把错误码写进日志；余额变化（且币种未变、非手动刷新）时自动弹气泡。
